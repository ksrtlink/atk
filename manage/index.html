How to get a token
  1. Open GitHub token settings ↗.
  2. Choose resource owner ksrtlink and only the atk repository.
  3. Give Contents: Read and write permission and set a short expiration.
  4. Generate the token and paste it above.

Your GitHub account must have write access. Branch rules still apply. Never share your token.
